**The review found a blocker in my own claim.** An `@oh` read-only review of
the session's commits reported that the CHANGELOG entry I had written
overstated the fix: a path whose parent is a file (`notes.txt/child.md`) still

can equal, so a full disk was demoted along with correctable path errors.

when the caller is a sub-agent, i.e. exactly the cases the original incident

confirmed the regression and the fix landed.

Every delegated diff in this session was verified by re-running tests and
