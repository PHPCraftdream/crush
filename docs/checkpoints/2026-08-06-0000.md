- **Every fix this round followed the same verification shape**: implement → build/vet/gofmt/lint clean → targeted tests green → revert-check (break the invariant, confirm the new test catches it, restore, confirm `git diff --stat` clean for the production file) → commit → `TaskUpdate` completed. Chose to commit it anyway with an explicit, honest caveat in the commit message (per the zero-trust verification discipline's honesty requirement) rather than either skip the test or falsely claim local verification. - **#319's fix reused the DB layer's already-correct ordering** rather than adding timestamp precision or a new tiebreaker column — `ListMessagesBySession` already sorts by `(created_at ASC, rowid ASC)`, so the CLI-layer bug was purely in re-deriving a worse order from a pre-sorted slice. - **#321's fix was display-layer only**, deliberately not touching the actual `RecordActivity`/heartbeat wiring — that wiring's current shape (gated on LLM stream chunks, not tool-call timers) is a previous deliberate design choice (task #300) specifically protecting against the opposite bug (a hung tool masked as healthy).
